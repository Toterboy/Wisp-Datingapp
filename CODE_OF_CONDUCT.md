# Verhaltenskodex / Code of Conduct

## Unser Anspruch

WispDating ist ein Projekt über respektvolle Begegnungen – das gilt erst recht
für die Zusammenarbeit am Code. Ziel ist ein offener, freundlicher und
diskriminierungsfreier Umfeld für alle, die beitragen möchten.

## Erwartetes Verhalten

- Respektvolle, sachliche Kommunikation – auch bei Meinungsverschiedenheiten
- Konstruktives Feedback auf Code und Ideen, keine Angriffe auf Personen
- Akzeptanz unterschiedlicher Hintergründe, Identitäten und Erfahrungsstände
- Rücksicht bei Themen, die die App berührt (Dating, Sicherheit, Minderjährige):
  kein herablassendes Verhalten gegenüber Betroffenen oder Fragenstellenden

## Inakzeptables Verhalten

- Belästigung, Beleidigungen, Diskriminierung oder Bedrohung jeglicher Art
- Sexuelle Sprache oder Inhalte in Projekt-Räumen
- Veröffentlichen privater Informationen anderer ohne Einwilligung (Doxxing)
- absichtlich eingespielte Sicherheitslücken oder Spam

## Durchsetzung

Verstöße können dem Projektbetreiber gemeldet werden:
**support@wispdating.de**. Berichte werden vertraulich behandelt.
Bei wiederholten oder schweren Verstößen können Beiträge ausgeschlossen
werden (Entfernen von Kommentaren, Sperre von Accounts/PRs).

Diesen Kodex adaptieren wir vom
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
Version 2.1.
